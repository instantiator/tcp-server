The current isometric view implementation is looking good. Please create a plan to address the feedback below. Although it's a numbered list, the order isn't important.

## Feedback

0. Ideally the isometric view would fill the remaining vertical space in the viewport, unless everything above the isometric view is already taller than the viewport, or the remaining space is too small, in which case it should take up a reasonable fixed height (as now) and the user can simply scroll down to see it.

1. It'd be good to be able to toggle labels with title information in the isometric view, eg. add checkboxes above the view for:
   - Agents: turns on labels above their heads with 'Agent: <role> (status)'
   - Roles: turns on labels above their heads with 'Role: <role>'
   - Furniture: turns on labels above each item, eg. 'Desk: <role|agent>', 'Pigeon holes', 'Whiteboard'
   - Rooms: turns on labels above the doors, eg. 'Task room: <task #>'

2. Where the prompt (eg. of a task, or of an assignment) is long, in a side-bar or tooltip, shorten it - ie. limit it to a certain number of characters (at the end of the last complete word), and allow the user to click a `...` on the end to read more.

3. Let's represent roles as folders/books instead of avatars (to help distinguish them from agents)
   - Cosmetic change: represent them as a small sprite (needn't be an accurate depiction of a folder/book - just something small for now)
   - When a new agent is created from a role, it should move to the nearest object depicting that role (to illustrate picking up a copy of the role), then move to its real target position (holding the role in some visual way to illustrate the role it has?)
   - This means that when an agent finishes working as a role, it should still return to its desk in the task room - it joins a pool of avatars waiting to be used (and keeps the role it had) - so if an agent with a role is called for again and there's a avatar waiting in the pool with that role, it can be used (and otherwise a new avatar is created which comes in the door, picks up the role, and proceeds to its task room, etc.)

4. Currently, the circles (representing reserved positions?) are drawn on top of the avatars - please draw them behind the avatars - it doesn't quite look right otherwise (this is assuming they are supposed to be flat on the floor tile)

5. Furniture should have tooltips so the user can discover what they are by hovering over them with a mouse
   - Tooltips should have a title (eg. "Pigeon holes") and a description of what they are for (eg. "agents come here when waiting for a response from users")

6. Doorways to rooms should have a tooltip indicating what the room is, eg. title: "1:1 room", and description: "Used for a conversation between 'role 1' and 'role 2'"

7. The scroll (direction) buttons should be arranged in an arrow key formation, eg. this is illustrative:

   ```text
        [^]
   [<-]     [->]
        [v]
   ```

   - Ideally all the buttons here would have icons instead of wording on the button.
     - This may require the import of an icon library. It's probably time. Please select a popular, commonly used, free, open source, permissively licensed icon library for the buttons.
   - Ideally this doesn't affect their accessibility (or perhaps because they work on a visualisation of the company (described in other ways by the screen reader) they don't matter and should be ignored by screen readers?)

8. For active agents, allow eavesdropping on their current thinking in the chat dialog (but read-only, because it is not a conversation) - show a button to open this from their tray (shown when the agent is clicked).
