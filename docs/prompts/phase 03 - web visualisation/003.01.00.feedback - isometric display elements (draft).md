The current isometric view implementation is looking good. Here's a little feedback:

- Where the prompt (eg. of a task, or of an assignment) is long, in a side-bar or tooltip, shorten it - ie. limit it to a certain number of characters (at the end of the last complete word), and allow the user to click a `...` on the end to read more.
- Let's represent roles as folders/books instead of avatars (to help distinguish them from agents)
  - Cosmetic change: represent them as a small sprite
  - When a new agent is created from a role, it should enter from the door, move to the role (to illustrate picking up a copy of the role's folder), then move to its real target position (holding the role in some visual way to illustrate the role it has?)
- Currently, the circles (representing reserved positions?) are drawn on top of the avatars - please draw them behind the avatars - it doesn't quite look right otherwise (this is assuming they are supposed to be flat on the floor tile)
- Furniture should have tooltips so the user can discover what they are by hovering over them with a mouse
  - Tooltips should have a title (eg. "Pigeon holes") and a description of what they are for (eg. "agents come here when waiting for a response from users")
- Doorways to rooms should have a tooltip indicating what the room is, eg. title: "1:1 room", and description: "Used for a conversation between 'role 1' and 'role 2'"

For active agents, allow eavesdropping on their current thinking in the chat dialog (but read-only, because it is not a conversation) - show a button to open this from their tray (shown when the agent is clicked).
