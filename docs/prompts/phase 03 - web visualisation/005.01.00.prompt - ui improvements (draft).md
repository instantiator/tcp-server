Please prepare a plan for the following UI improvements:

## Agent activity visualisation

When an agent is working, it should show a thought bubble above its head (but not obscuring the role indicator 'hat'). The thought bubble should be animated (smaller bubbles appear, then the bubble appears, then everything clears, and the sequence repeats), unless that is not trivial - in which case we can handle it in future. Clicking the thought bubble should open the 'eavesdropping' view of the agent's chat panel directly.

## Companies list

The companies list should be a series of cards of fixed width, arranged in a horizontal flex that wraps.

Each piece of data on the card should be shown in a list, formatted as "[icon] [count] [objects]", eg.

```markdown
[agent icon] 2 active agents
[task icon] 1 active task
[enquiry icon] 0 open enquiries
```

Clicking anywhere on the card should open that company view.

## Company view

Make UI modifications with styling (ideally with common css classes, so we can shift this all into a design system soon). Ideally the way we style and arrange should have minimal / no impact on the accessibility.

### Tray and FAB

The tray should be vertically-scrolling within itself.

The FAB should be a plus icon, in a circular button, rather than the word 'Add'.

When the tray is shown, the FAB should be positioned relative to the tray's left-hand edge.

The tray and FAB should be animated into position (eg. tray slides in from the right, and FAB moves relatively to it).

#### Tray content

The 'Close details' button should be a small, circular button with a close icon, floated to the top right of the tray.

The follow button should be a round button with a crosshairs icon, by the name of the subject of the tray.

### Top bar

Let's arrange the top part of the UI:

- Top bar should be sticky
  - The application name (TCP) is on the top left followed by the company name (if in a company view)
    eg. TCP
    eg. TCP: Company Name
  - The Account control is top right, and is a button with a 'user' icon

### Heading

- Top of the page should be the breadcrumbs
- A little smaller than default font size
- Arranged horizontally, eg.
  Companies > Test Company

### Company view

- Please float the directional and full screen controls in the bottom left
- When the bottom bar containing chat dialogs is open, these controls should be positioned relatively to that
- The label checkboxes can float at top left
- By floating all the controls, the isometric viewport should be able to take up the full space available from the tabs to the bottom of the view
- The show details for control should look like another button next to the full screen button, with a magnifying glass for an icon (instead of text)

### Activity view -> tabs

Rather than an activity view, each section in this view should be its own tab with its own title.

1. Active agents
2. Tasks
3. Consultations
4. Enquiries
5. Chats

The tab title of each should have a highlight coloured badge with the number of items it shows.

Any filters in these tabs should be retained between switching away and returning to the tab.

### Isometric view

The isometric view can be moved with the arrow buttons. It should also be draggable.
