## Context

Parity row 2: an administrator can list every company with `tcp-cli list-companies` (`GET /api/company?all=true`), but the web Companies page only ever asks for the caller's own companies. This plan adds an admin-only "My companies / All companies" toggle to that page. **No backend change is needed.**

### What exploration found

- **Backend is done.** `GET /api/company?all=true` (`apps/backend/apps/tcp-server/src/api/api.company.controller.ts:120-149`) returns every company to an admin, 403 to anyone else. Each item carries `memberType` (`null` when the caller isn't a member), already in `schema.d.ts:2200`.
- **Admin flag in the browser:** `useSystemStatus().data?.admin` (`src/api/hooks.ts:171`, used by `shell/Header.tsx:82`). `staleTime: Infinity`, and the header already calls it on every page, so it's usually cached.
- **The hook already takes the flag.** `useCompanies(params: CompanyListParams)` (`src/api/endpoints.ts:52`), where `CompanyListParams = GetQuery<'/api/company'>` (`query-keys.ts:81`). The key includes the params, so the two lists cache apart.
- **Page:** `src/pages/CompaniesPage/CompaniesPage.tsx`. Its doc comment says it "only ever asks for mine". That becomes false and must be rewritten. The comment's "(002.05)" reference is stale too.
- **Admins can already open any company** (they pass every company check), including Admin → Company → Delete from 002.02. Nothing to add there.
- **Toggle styling:** `.react-aria-ToggleButton` and `[data-selected]` exist in `src/styles/base.css:195-212`. No `ToggleButtonGroup` is used yet. URL search params: `TasksList.tsx:79` uses `useSearchParams`.
- **Browser tier:** the test user and the machine client are both admins in the testing stack (`start-deployment.sh:568`). A company the machine creates has the machine as its only member, so it shows up only in "All companies". `companies.spec.ts` already gets a machine token and is in `SIGNED_IN_SPECS` (`playwright.config.ts:26`).

### Decisions agreed with you (2026-10-18)

| Decision           | Choice                                                                                                                       |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| Control            | RAC `ToggleButtonGroup` with two buttons, "My companies" and "All companies", next to **New company**. Shown to admins only. |
| Persistence        | URL query `?scope=all`. Reload and Back keep it.                                                                             |
| Non-member marking | In the all view, a card with `memberType === null` shows "Not a member".                                                     |

### Choices made in the design (say if you disagree)

1. **Non-admins never send `?all`.** `scope=all` counts only when `isAdmin` is true. A non-admin who opens `?scope=all` gets their own list and no toggle, not a 403.
2. **No extra wait for the admin flag.** On a cold load of `?scope=all`, the page may fetch "mine" first and then "all" once the status arrives. `// ponytail:` comment; gate the fetch only if the flash is noticed in use.
3. **Choosing "My companies" removes the param**, so the default URL stays `/companies`. Use `setParams(..., { replace: true })`, so flipping the toggle doesn't stack history entries.
4. **The all view has its own wording.** Loading, error and empty text say "all companies" or "the companies" rather than "your". The empty state keeps the New company button.
