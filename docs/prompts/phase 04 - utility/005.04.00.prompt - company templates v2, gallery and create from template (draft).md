> ## Company templates
>
> > 📝 **In a draft, not implemented:** [deferred-work.md](../deferred-work.md#company-definitions-as-zip-files) ("Company definitions as zip files") covers company, roles and knowledge, loaded by `tcp-cli`. This gap extends it with MCP services, records, schedules, reports and hooks.
>
> **Today:** `scripts/test-data/companies/*.json` describe the company row only
> (slug, name, description, context, LLM config). Roles and knowledge are added
> one CLI call at a time.
>
> **Recommend:** a template package: company, roles (prompts, skills, model
> minimums), knowledge packs, MCP service attachments (without secrets, which
> are listed as "you'll need"), record table schemas, schedules, reports, hooks.

> - A gallery in the web UI. "Create company" starts here.
> - Version the format from day one.
> - First template: **cottage industry**.

## Done in 002.03

[002.03](002.03.01.plan%20-%20company%20template%20format%20v1%20with%20import%20and%20export.md) did most of what the quoted recommendation above asks for. The quote stays as the original gap. Do not redo these:

- **Import and export, API.** `POST /api/company/import/preview`, `POST /api/company/import`, `GET /api/company/:companyId/export`. See `apps/backend/apps/tcp-server/src/templates/`.
- **Import and export, CLI.** `import-company`, `export-company`, `new-template`, `list-templates`, `template-source`. See `apps/backend/apps/tcp-cli/src/commands/`.
- **Import and export, web.** Import a zip, "Export as template" in Admin, and a template sources screen in the admin system menu.
- **The gallery with sources.** Built-in, directory and GitHub sources (`GET /api/template`, `/api/template-source`), kept in the database and set from `TEMPLATE_SOURCES`. The web `TemplateGalleryDialog`.
- **New company opens the gallery.** "Start from scratch" leads to the plain dialog.
- **Versioning.** `formatVersion` is in every `company.json`. A newer version is refused.
- **The cottage industry template, and `blank` and `basic`.** See `templates/`. The blank template's `README.md` is the format reference.
- **Knowledge licences.** `license`, `source` and `attribution` in front matter.

- **Offer a first task** after import (see below).
- **Gallery improvements.** For example previews or screenshots of a template, search and filtering, and showing what a template needs before it is chosen.

## Also: the plain create dialog (from 002.02)

[002.02](002.02.01.plan%20-%20web%20ui%20create%20and%20edit%20a%20company.md) built a plain **New company** dialog (name, slug, description, time zone, company context, chat and embedding models). The gallery now opens before it, with "Start from scratch" leading to that dialog. That was done in 002.03. Two steps of the original create flow remain for this prompt:

- **List required secrets.** Waits for 003.00 (secrets). A template should name the keys its services need, and the create flow lists which are missing.
- **Offer a first task.** A plain company has no roles and no planner, so 002.02 lands on Admin → Roles instead. A template brings roles and a planner, so the flow can end by offering a first task.
