## Consultations

The last piece of work before we can do that is to show consultations in the web UI transcripts for both agents involved.

- consulting agent: initiates a consultation
- consulted agent: responds

In the consulting agents chat view, show the consultation inline with a visual indicator, perhaps similar to how `> quoted text` is commonly shown in markdown (ie. with a left border and a small indent). Show a waiting indicator while the consulted agent thinks / responds.

In the consulted agents chat view, this conversation (and reasoning) can be shown as a regular conversation.

The `MAX_STREAMS` budget caps the number of streams at 12. This isn't yet an issue, although in future it will be. Propose options to keep the number of streams needed low (eg. deliver the consultation through the consulting agent's stream).

## Retiring the TUI

You asked:

> Does it mean deleting `lib/tui/`, the roster and `terminal-kit`, or only deprecating it? Deleting it is a large removal, and it touches docs, tests and the `--no-tui` flags.

It really does mean removing all traces of it from documentation and the application (including any libraries it used that are no longer required - audit and remove all unneeded libraries). This should significantly simplify the project.
