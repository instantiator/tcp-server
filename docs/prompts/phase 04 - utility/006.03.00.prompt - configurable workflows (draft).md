## Templates (from 002.03)

- Workflows become part of the template format (v2, planned in 005.04). A format change means bumping `formatVersion` (to 2 or higher). v1 refuses unknown keys, so an older server will refuse the new template with its "made by a newer version of TCP" message, which is the right result. The new code must still read version 1.
- `cottage-industry` candidates: enquiry, then draft, then promises review, then owner; and order, then record, then packing list, then postage.
- Replace the matching planner guidance in the template with the workflows once they exist. The planner should pick a workflow before it invents a plan.
- Export writes workflows back, and import validates that every role a workflow names exists. The format is documented in `templates/blank/README.md`, which travels inside every blank download. Update it in the same change, so it never lags behind the code.
