## Templates (from 002.03)

- The `cottage-industry` **listing writer** and **order manager** should use the marketplace services (Etsy, eBay, Shopify) once they exist. Add them to the template as service attachments (format v2, 005.04), with the secrets listed as "you'll need" (003.00). A format change means bumping `formatVersion` (to 2 or higher). v1 refuses unknown keys, so an older server will refuse the new template with its "made by a newer version of TCP" message, which is the right result. The new code must still read version 1.
- Attach each service only to the roles that need it, with tool allow-lists. Anything that changes a live listing or an order goes through approval.
- Update both role prompts to say how to use the services. The format is documented in `templates/blank/README.md`, which travels inside every blank download. Update it in the same change, so it never lags behind the code.
