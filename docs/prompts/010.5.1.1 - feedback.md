I've made a couple of changes to help resolve an issue with token auth, and I've got lcp-cli and token authentication working. A little feedback from testing:

## not streaming

When viewing an assignment, I see the historical events, but events don't seem to stream - ie. I don't see reasoning or responses or other events like tool calls, but when I close and re-open the assignment panel I _then_ see them, as I guess they were retrieved from the audit log.

In fact, this seems to be the case at company and task level, too - ie. changes aren't coming through as streamed events, but reloading the panel (or, for the company, exiting and re-launching lcp-cli) seems to work.

I noted that there's a `r refresh` option on the company panel that also doesn't seem to have an effect (ie. doesn't try to load).

## assignment counts

On re-entering lcp-cli, the company pane showed the task that had been created (good), but it showed `(in progress: 0/0)` which is incorrect, by this time the planner had created a plan with 1 step.

And, in fact, therefore there were 3 completed assignments:

- cat assistant (plan)
- cat assistant (implement)
- cat assistant (qa)

and at the next viewing, also an in-progress assignment:

- cat assistant (finalise)

At this point, it then showed: `(finalising)` which is good.
