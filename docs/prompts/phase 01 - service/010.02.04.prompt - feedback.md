## `chat` and `tui` verbs

At the moment, the TUI for lcp-cli is launchde using the `chat` verb with a company instead of a role.

Instead, please split `chat` into `chat` and `tui`. The TUI should be launchable with the `tui` verb and a company. No need for it to launch directly into an orphaned chat assignment with a role. That's a function of non-TUI `chat`.

## Initiate task

Action: Please incorporate this feature into the `docs/prompts/010.02.05*` plan.

From the company panel in the TUI, it should be possible to create a new task.

Please add a simple initiate task panel to the TUI interface. It should allow the user to type a task prompt, and select a planner role (or leave it on the default role provided by the company if any). It should allow the user to add and remove expected filenames for expected outputs from the task. (We'll add materials in a later improvement.) It should have a "Start task" 'checkbox' that (if selected), causes the task to start when created.

It should validate for: a non-empty prompt, a chosen role. (It's ok to have 0 expecteds.)

If the task is succesfully created, the TUI should exchange the panel for a task monitoring panel for that task.

NB. The new `TaskPane` company described in 010.02.05 should offer an option to start the task if hasn't been started.
