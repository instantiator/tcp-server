The `store-knowledge` verb should work as follows:

1. Accept: pdf, docx, markdown, html
2. Generate OKF documentation with suitable headers
3. Store in a suitable location
4. Add to an index file
5. Initiate RAG indexing

Possible supporting library: https://github.com/Nano-Collective/get-md

Is it a good option? Are there other libraries that could do this? We are looking for:

- does what we need
- mature (well tested, well adopted)
- well supported
