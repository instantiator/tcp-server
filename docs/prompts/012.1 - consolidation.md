## Queueing

We currently connect to BullMQ queue(s) from a number of locations. Let's consolidate all access to BullMQ and Redis with a shared interface for working with queues, which can then be implemented by a QueueService. Then we can build an adapter for it that implements the interface, and works with BullMQ/Redis.
