## Implementation

I think `@nestjs/swagger` is the right package - but recommend an alternative if there's a more appropriate choice. There's documentation from NestJS here about how to implement this: https://docs.nestjs.com/openapi/introduction

As always, please use the latest version of the dependency, and `npm audit` dependencies. Please include a summary of any current issues with dependencies, and make a recommendation to resolve them as a part of this work.

Please also update `lcp-cli` - just as we have `open-document-store` let's add an `open-swagger` verb that prints and opens the url for the swagger page for one of the apps. It should have an option to specify the service, with `--service` (required), to name the app to open swagger definitions for, and `--no-open` (optional) to just print but not open the url.

Accepted options for `--service` should be:

- `lcp-server`
- `lcp-agent`
- `lcp-mcp-interactions`
- `lcp-mcp-memory`
- `lcp-mcp-stotage`

If there's a way to enrich the swagger output with information about the endpoints, parameters, and overall directions for usage (eg. with examples, and descriptions drawn from the tsdoc/jsdoc code comments?) please include that in the plan.
