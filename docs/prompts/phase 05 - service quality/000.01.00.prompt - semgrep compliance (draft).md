# Semgrep compliance

```bash
# install
brew install semgrep
```

```bash
# evaluate
semgrep --config "auto" \
  --exclude "dist" --exclude "build" --exclude "*.spec.ts" \
  --json --output temp/semgrep-report.json .
```

`semgrep` reveals a number of issues. A recent run report: `temp/semgrep-report.json`

Run a fresh assessment, group issues:

- Estimated as trivial, or small effort
- Estimated complex enough to require a plan

Prepare a plan to resolve all trivial / small effort items now.

Include steps in the plan to write prompts to plan resolution of complex issues - group those issues together in prompts wherever possible.

The plan should develop an amendment to pre-push and CI to adopt semgrep with a baseline / list of accepted issues considered non-serious, and the ability to.

The plan should also modify the planning skill for future work, to run semgrep before the final stage of every plan, and to handle any new issues to fix issues as they occur.
